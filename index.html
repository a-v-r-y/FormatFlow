How compound extensions are handled

We never judge a file by its final suffix alone. The detector checks the longest match first: backup.tar.gz is detected as .tar.gz → Archives / Compound, not as a plain .gz; brain.nii.gz is Medical Imaging, not a generic archive; app.pkg.tar.zst and archive.7z.001 are treated as single compound types. If a compound type has no real in-browser engine, it stays identify-only.

Common questions

Is there a file-size limit?

There's no artificial limit, but everything runs on your device's memory. Most phones and laptops handle images up to ~50 MB and PDFs up to a few hundred pages comfortably. For a very large PDF, converting to images creates one image per page — start with a smaller file if your device feels slow.

Why can't I convert a PDF back into an editable Word file here?

A PDF stores how a page looks, not the original document structure, so a faithful PDF → Word conversion needs a server-grade engine. Here you can reliably extract a PDF's text (PDF → TXT) and its pages as images — which covers most everyday needs honestly, instead of producing a broken .docx.

Will converting JPG to PNG make my photo higher quality?

No converter can add detail that isn't there. PNG will preserve exactly what's in the JPG (in a larger file), while JPG → JPG at a lower quality setting will shrink the file at some quality cost. Use the quality slider and max-width options when your goal is a smaller file for email or upload limits.

What happens to transparent backgrounds?

PNG and WEBP keep transparency. JPG has no transparency, so transparent areas are filled with the background colour you choose in Settings (white by default).

Why does the site list 48 categories if it cannot convert all of them?

The 48-category list is a detection registry, not a promise. It lets the site recognise what a file is — including executables, disk images, ROMs, CAD and DICOM files — and organise the browser. Conversion buttons only appear where a real in-browser engine exists and has been implemented here (images, PDF, documents, data, subtitles SRT↔VTT, audio→WAV, ZIP↔TAR and TAR.GZ→ZIP). For everything else the file card says “identify only” and offers no button, rather than producing a fake file.

How are .tar.gz and .nii.gz different?

Both end in .gz, but they are not the same thing. The detector checks compound extensions first with the longest match: .tar.gz is an archive (and can be repacked to ZIP here), while .nii.gz is a medical-imaging file and is identify-only. Judging by the final “.gz” alone would get that wrong.

Does audio → WAV make a low-quality MP3 sound better?

No. Decoding an MP3, OGG or M4A to WAV preserves what the browser can decode in an uncompressed file — it does not restore quality lost in the original compression. The file will usually be much larger.
